# 07 — 手动测试所有功能

**What to build:** 对所有实现的功能进行手动测试验证，确保符合需求规范。

**Blocked by:** 02, 03, 04, 05, 06 — 所有功能实现完成

**Status:** ready-for-agent

## Acceptance criteria

### 页面初始化测试
- [ ] 验证进入 `/conversations` 页面时自动创建新对话
- [ ] 验证新对话标题显示为 "MediTrace 对话"
- [ ] 验证页面直接进入聊天状态，无需选择对话

### 标题动态变化测试
- [ ] 验证新对话状态标题正确显示 "MediTrace 对话"
- [ ] 验证选择已有对话后标题变为 "有效提取用户的问题"
- [ ] 验证切换回新对话时标题正确更新

### 对话列表展示测试
- [ ] 验证每条对话仅占一行
- [ ] 验证标题（左侧）和时间（右侧）位置正确
- [ ] 验证长标题滚动效果正常
- [ ] 验证鼠标悬停时时间变为 "..."

### 三点菜单功能测试
- [ ] 验证点击 "..." 显示弹框
- [ ] 验证弹框包含重命名和删除选项
- [ ] 验证重命名功能正常工作
- [ ] 验证删除功能正常工作（带二次确认）
- [ ] 验证点击外部区域关闭弹框
- [ ] 验证 ESC 键可关闭弹框

### UI 布局测试
- [ ] 验证第二个头部已被移除
- [ ] 验证聊天内容区域空间增大
- [ ] 验证整体布局符合现代 AI 对话应用风格

### 回归测试
- [ ] 验证消息发送功能正常
- [ ] 验证流式响应功能正常
- [ ] 验证侧栏折叠/展开功能正常
- [ ] 验证移动端适配正常
