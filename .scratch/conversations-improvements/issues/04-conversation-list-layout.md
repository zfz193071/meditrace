# 04 — 重构对话列表为单行展示 + 滚动效果

**What to build:** 将对话列表从多行展示改为单行展示，左侧显示标题，右侧显示时间，鼠标移入时标题滚动、时间变为"..."。

**Blocked by:** None — can start immediately

**Status:** ready-for-agent

## Acceptance criteria

- [ ] 每条对话仅占一行展示
- [ ] 左侧显示对话标题，右侧显示时间
- [ ] 移除原有的最后消息内容和日期显示
- [ ] 鼠标移入时，长标题能够自左向右滚动显示
- [ ] 鼠标移入时，时间显示变为"..."
- [ ] 保持点击对话项切换到该对话的功能
- [ ] 保持当前选中对话的高亮样式

## User Stories

- 作为用户，我希望对话列表每条仅占一行，这样我可以在有限空间内看到更多对话记录
- 作为用户，我希望对话列表左侧显示标题、右侧显示时间，这样我能快速获取对话的关键信息
- 作为用户，我希望鼠标移入对话时标题能够自左向右滚动，这样当标题过长时我仍能完整看到内容
- 作为用户，我希望鼠标移入对话时时间显示变为"..."，这样我能知道有更多操作可用

## Technical Decisions

- 使用 CSS `@keyframes` 实现标题滚动动画
- 滚动动画应使用 `transform: translateX()` 而非 `width/height` 变化，保证性能
- 鼠标悬停时通过 CSS 类切换时间显示内容
- 使用 flexbox 布局实现左右对齐
