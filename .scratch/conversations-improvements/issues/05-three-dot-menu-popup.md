# 05 — 实现三点菜单和右下弹框功能

**What to build:** 点击对话列表项右侧的"..."按钮，弹出右下弹框，包含重命名和删除选项。

**Blocked by:** 04 — 重构对话列表为单行展示 + 滚动效果

**Status:** ready-for-agent

## Acceptance criteria

- [ ] 对话列表项右侧显示"..."按钮（鼠标移入时显示）
- [ ] 点击"..."后弹出右下定位的弹框
- [ ] 弹框包含"重命名"和"删除"两个选项
- [ ] 点击"重命名"后允许修改对话标题
- [ ] 点击"删除"后删除对话（保持现有删除逻辑，带二次确认）
- [ ] 点击弹框外部区域关闭弹框
- [ ] 弹框支持 ESC 键关闭
- [ ] 重命名支持回车键确认

## User Stories

- 作为用户，我希望点击"..."后出现右下弹框，这样我能方便地访问对话管理功能
- 作为用户，我希望在弹框中能够重命名对话，这样我能更好地组织和管理我的医疗咨询记录
- 作为用户，我希望在弹框中能够删除对话，这样我能清理不再需要的咨询记录

## Technical Decisions

- 使用绝对定位实现弹框位置（对话列表项的右下角）
- 添加状态管理当前打开的弹框（`activeMenuConversationId`）
- 重命名功能：需要调用后端更新对话标题的 API（依赖 Ticket 01 的验证结果）
- 删除功能：复用现有的 `handleDeleteConversation` 函数
- 点击外部关闭：添加全局点击事件监听
- ESC 键关闭：添加键盘事件监听
