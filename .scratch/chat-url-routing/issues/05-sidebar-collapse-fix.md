# 05 — 侧栏折叠时隐藏"新建对话"按钮

**What to build:** 优化侧栏折叠交互，确保当用户点击折叠按钮收起侧栏时，"新建对话"按钮完全隐藏，节省屏幕空间。

**Blocked by:** None — can start immediately（与 URL 路由功能相对独立）

**Status:** ready-for-agent

**Acceptance criteria:**
- [ ] 验证当前侧栏折叠行为：
  - 点击折叠按钮（◀/▶），侧栏宽度变为 0（`w-0`）
  - 侧栏内容（包括"新建对话"按钮）完全不可见
  - 如果当前行为已满足需求，则标记为"无需修改"
- [ ] 如果当前行为不满足需求，修改侧栏折叠逻辑：
  - 方案 A：保持侧栏宽度但隐藏内容（折叠图标保留，内容区域隐藏）
  - 方案 B：完全隐藏侧栏（包括"新建对话"按钮）- 推荐
  - 方案 C：折叠时只显示图标，隐藏文字和按钮
- [ ] 确保折叠状态在页面刷新后保持（可选：使用 localStorage）
- [ ] 测试移动端响应式行为：
  - 移动端默认折叠状态正常工作
  - 折叠/展开按钮在移动端可见且可用
  - 点击外部区域关闭侧栏（移动端）
- [ ] 添加适当的过渡动画（保持现有的 `transition-all duration-300`）

**技术备注:**
- 当前实现位于 `src/frontend/app/chat/page.tsx` 第 67-68 行和 798-804 行
- 侧栏样式：`sidebarCollapsed ? 'w-0' : 'w-80'`
- 折叠按钮：第 798-804 行的 `toggleSidebar` 函数
- 如果当前 `w-0` 已经实现完全隐藏，则此任务标记为完成

**UX 细节:**
- 折叠时侧栏完全不可见（宽度为 0）
- 展开时侧栏宽度 80（`w-80` = 320px）
- 过渡动画平滑（300ms）
- 折叠按钮 Tooltip 显示"展开侧栏"/"折叠侧栏"
