## 工单关闭规则

状态为 `TODO → IN_PROGRESS → DONE`；缺外部配置或人工验收时记 `BLOCKED` 并列出具体缺项，不用 Mock 成功替代外部集成验收。依赖未完成则保持 TODO。

每票必须写明：改动文件／提交、验收项逐项结果、命令及结果、失败路径证据、残余限制。若修复既有 bug，增加项目要求的 BUGFIX 文档。所有新增必需工作必须归入现有票或显式新增票并更新覆盖表；禁止把必要工作标为“后续优化”后关闭版本。

V1 完成是 24 票全部 DONE 且 QUALITY-AND-RELEASE 的发布门槛通过，不意味着已有真实医疗用户、临床验证或商业收入。
