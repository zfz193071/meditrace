# MT-08 结构化提取与模型 Adapter

目标：用同一 Interface 提供 Fake 与 DeepSeek 提取，并保证采纳事实有有效证据。

先读：[事实和引用规则](../DOMAIN-AND-API.md)、ARCHITECTURE extraction Interface。

## 实施范围

- 独立提取提示词、输出 Schema、模型配置；不调用旧诊断提示词／医学知识硬编码函数。
- 输出字段固定，保留未知／否定／时间／单位；引用用 Document、page、quote，由服务器定位。
- Fake Adapter 提供正常、非法 JSON、截断、假引用、超时、usage 缺失等场景；不把固定输出冒充真实结果。
- DeepSeek Adapter 一次请求、无自动重试／工具执行；记录请求和返回 model 标识、usage、供应商请求 ID，原文不写运行日志。
- 验证格式、来源归属、文本支持的最低结构要求与 quote；文档内“忽略指令”等被当作普通数据。
- 校验完整输入 token 安全上界与输出上限，超限先拒绝；缺价格／模型配置由上层 fail closed。

## 验收

- [ ] Fake 和真实 Adapter 返回同一领域结构，输入／输出契约快照通过。
- [ ] 模型生成假页码、越权文档、重复短 quote 未消歧、非法日期／单位改写不能被静默采纳。
- [ ] 未提供不输出“无”，不同时间陈述不会合并成一个无时间事实。
- [ ] JSON 错误与供应商失败返回明确 code，绝不退化到旧诊断或硬编码成功。
- [ ] 真实 Adapter 的 HTTP 请求结构、超时、响应解析和错误行为经 Mock HTTP server／录制响应验证；供应商实际往返及质量验收由 MT-20 在完整权限／预算链路就绪后完成。

验证：Fake 契约、Mock HTTP server、错误响应和录制回放；本票不直接发起付费请求，不声称通过真实模型集成验收。
