# MT-17 Stripe 测试购买与会员账户

目标：完成受服务端验证的会员购买闭环，保留原有付费权限要求而不开展真实收费。

先读：[支付回调与权益](../DOMAIN-AND-API.md)、PRODUCT 运行模式。范围：billing Module、订单／webhook、`/account`、支付返回页。

## 实施范围

- 服务端固定测试商品、金额、币种；Checkout payment 模式、30 天／20 次、无自动续费。
- 创建订单与 Checkout 幂等，仍有效会员禁止再购；页面明确测试支付、不收真实费用。
- 验证 raw-body 签名、事件时效、test mode、订单归属、金额／Price；以支付状态发放一次权益。
- 处理重复、乱序、pending、延迟支付、退款／撤销以及事件处理失败恢复。
- 支付回跳只查询服务器订单，恢复原包和已保存草稿，不自动启动 AI。
- 未受邀测试会员仅可 Fake；修改客户端环境／Price／metadata 无法获得真实 AI 或额外额度。

## 验收

- [ ] 实际 Stripe 测试 Checkout→签名 webhook→权益生效往返成功，并有脱敏事件 ID 证据。
- [ ] 伪造成功页／签名／金额／账号无权益；同事件及不同事件的同笔付款均只发一次。
- [ ] 退款事件先到或晚到都不会被后续完成事件重新激活；处理失败可重入恢复。
- [ ] 取消／失败付款保留资料，支付成功不自动生成；会员过期仍可手动编辑与导出。
- [ ] Live key、live Price 或 livemode=true 在 V1 被拒绝，公共沙箱不会间接消耗真实 AI 费用。

验证：签名事件与时间测试、真实测试环境购买、账号页面组件测试；无需真实付款。
