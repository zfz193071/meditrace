# MT-06 按页解析、文字版本与证据锚点

目标：把来源文件转为可复查的页文字，可靠拒绝不支持资料。

先读：[Fact 与 Evidence](../DOMAIN-AND-API.md)、PRODUCT 输入限制。范围：pypdf 解析、粘贴文字、页面访问接口和定位工具。

## 实施范围

- 固定 text-v1 规范化，保存按页文字、哈希、解析器版本、quality；粘贴文字作为单页 Document。
- 子进程执行 PDF 解析，设置 20 秒解析超时、输出长度／页数／内容流上限，终止仅限自己创建的进程。
- 区分纯空白页与含内容但无可提取文字页；不能可靠判断时标记需替换，不默认为正常。
- 处理加密／损坏／扫描／混合页／超页 PDF；失败有具体文档和页信息，不静默截断。
- 实现 quote 唯一定位、上下文消歧和 code point 区间验证，供提取与 UI 使用。

## 验收

- [ ] 中英文姓名、emoji、组合字符、换行、重复短句的 offsets 在 Python／TypeScript 往返一致。
- [ ] 多页原文页码稳定，内容哈希一致；旧 text-v1 不因重新部署被重新规范化。
- [ ] 无法提取的非空页阻止自动核对该包；不会把未读页当成没有信息。
- [ ] 超时／解压膨胀／过长输出不会导致无界内存或无限等待。
- [ ] 解析错误不删除其他成功文档；文件状态和配额结算一致。

验证：合成 PDF parser corpus、资源限制测试、跨语言 offset golden 测试，未调用模型。
