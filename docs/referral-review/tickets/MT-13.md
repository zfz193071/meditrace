# MT-13 交接摘要、文本与 PDF 导出

目标：交付与审核快照一致、可阅读且保留未解决事项的交接材料。

先读：[R08 与人工完成含义](../PRODUCT.md)、QUALITY Q19。范围：纯 handoff model、文本／PDF 渲染、授权导出路由。

## 实施范围

- 从 snapshot 生成统一 view model：身份状态、转诊原因、用药／过敏、已有报告、未解决项、人工补充、来源索引、版本和确认时间。
- 实现复制文本、下载 txt、服务端 fpdf2 PDF；英文模板支持 Unicode 名称，确认使用字体许可。
- 正确分页、表头与页脚；不以一页为目标截断内容。单个响应超平台大小时明确错误。
- 历史 snapshot 下载增加“Historical revision”派生水印，不更改存储快照本体。
- 固定 demo 使用同一 handoff view model，浏览器打印／保存 PDF 可无需后端业务写入；真实工作区支持服务器 PDF 下载。

## 验收

- [ ] PDF、txt、界面摘要的已确认字段、修正内容、未解决项及版本一致。
- [ ] 长稿、缺失字段、Unicode、未解决身份、多页来源均可读且无裁剪。
- [ ] 未登录／越权／删除／到期均无法下载；额度为零不阻止合法导出。
- [ ] 原始 PDF 不上传 IPFS，不含链上地址或诊断置信度；导出不调用 AI。
- [ ] 实际渲染短／长 PDF 逐页检查并保存合成样例证据。

验证：view model snapshot、文本一致性、授权测试和 PDF render QA；开发本票时使用适用 PDF 技能。
