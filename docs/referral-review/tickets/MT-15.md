# MT-15 双栏证据定位与人工审核 UI

目标：点击问题可立即看到依据，并在同一工作台完成处理。

先读：PRODUCT 核对界面与人工完成规则；DOMAIN Evidence/Resolution。

## 实施范围

- 事项列表按类型／状态筛选，选择项显示清单要求和关联事实；缺失事项显示检查范围。
- 原文视图按 Document／page／offset 精确高亮；冲突同时显示两侧证据，来源文字与 PDF 页预览关联。
- PDF 仅安全预览或下载，不执行脚本；证据权威为 normalized page text，避免承诺像素级位置。
- resolve/dismiss/defer/reopen、理由、人工更正、版本冲突、历史参考和确认动作。
- 旧 revision／run 明显标 stale，确认按钮解释被禁用的原因；未解决身份问题常驻可见。

- 以一个身份差异合成包完成导入／已保存来源 → 核对结果 → 双侧证据 → 人工处理 → 确认 → 导出的核心流程；接入 MT-13 导出组件，不让演示停在事项列表。
- 同一案例展示更换资料后的 stale 提示和旧审核记录；生成结果由预载 fixture 驱动，工作区真实核对仍由用户手动触发。

## 验收

- [ ] DOB 差异一次点击显示两个正确引用；缺失项没有伪造的“原文证据”。
- [ ] emoji／组合字符／重复词／长页准确高亮，引用点击不能跳到别的版本。
- [ ] 非法 HTML／Markdown／PDF 链接不会执行；通过键盘可定位并操作所有审核项。
- [ ] 409 保留用户未保存的修正供对比，不能自动覆盖服务器版本。
- [ ] 390px 视口可以切换事项和证据，不横向丢失关键按钮；状态不用颜色单独表达。

- [ ] 一份可复现的核心案例能走到确认和实际导出，记录各步及来源版本；自动浏览器仅操作预载结果和非生成动作。

验证：固定结果组件测试、背景浏览器审核／定位测试，不自动点击生成按钮。
