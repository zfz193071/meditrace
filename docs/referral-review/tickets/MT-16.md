# MT-16 无登录示例与英文产品入口

目标：雇佣者无需注册、付费或等待模型即可理解产品的核心价值。

先读：PRODUCT R01、运行模式与页面。范围：首页、`/demo`、示例清单与静态资产。

## 实施范围

- 首页英文说明核心任务，主 CTA 为 Try demo，次 CTA 为 Open workspace；包含合成资料／预先生成标识。
- 3 个示例复用实际证据和审核 UI，通过本地内存 store／demo Adapter 驱动，不复制另一套业务呈现。
- 支持选择问题、查看双侧证据、人工处理、确认、复制／打印和重置；刷新回初始状态。
- 补附件演示用预置 second revision／结果快照，明确“Load prepared revision”，不播放假模型调用动画。
- 首页链接架构／评估／代码，暂未达到的指标不宣传；不显示医疗合规或临床正确性承诺。

- 三个公开案例明确为正常资料、缺少声称已附的报告、出生日期冲突；各自说明应观察的结果，复用 MT-03 合成资料与标注，不挑选后冒称质量评估结果。
- 首页首屏提供一句英文定位、Try demo、代码入口与作品状态；正常进入演示不要求 GitHub 登录、会员或模型密钥。代码／评估链接须指向真实存在内容，未完成项标明待完成。
- 将身份冲突案例作为 60—90 秒录制主路径；提供明确的开始／重置入口，固定示例直接加载结果，不模拟生成等待。

## 验收

- [ ] 无登录完整走示例核对与导出；网络中无模型、支付或私人资料写入请求。
- [ ] 示范中的资料更新会使旧结果过期，载入新版后状态正确，不掩盖版本逻辑。
- [ ] 编辑／重置不会改变其他访客数据，也不持久化用户输入。
- [ ] 第一屏能看懂任务与入口；三个指定视口可用，关键示例无需说明即可操作。
- [ ] 示例与真实工作区共用数据契约和关键 UI，而非另做一份只会播放的页面。

- [ ] 正常、缺附件、身份冲突三个入口均可访问且结果与标注一致；未解决身份问题在确认／导出中保持突出。
- [ ] 首次访问者按页面提示即可完成“选择案例 → 查看证据 → 人工处理 → 导出”；记录自动检查与实际人工试用的区别，不虚构用户反馈。

验证：静态资产／契约校验、网络断言、背景浏览器的固定示例操作。
