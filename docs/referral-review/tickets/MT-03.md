# MT-03 接收清单、合成案例与标注

目标：开发、演示和评估都使用明确、可追踪的合成资料及规则。

先读：[产品清单](../PRODUCT.md)、[评估规格](../QUALITY-AND-RELEASE.md)。产物放 `fixtures/referral-review/`，不使用真实患者、医院标志或未经许可的文档。

## 实施范围

- 固化 `outpatient-referral-demo@1` 的 C01—C08，声明其演示性质；规则定义使用机器可读格式并校验版本。
- 编写至少 30 包合成资料及标注，10 开发／20 冻结测试，稳定 ID 与内容哈希；覆盖全部指定类型、负例、日期与 Unicode。
- 选 3 个开发集案例作为公开示例：缺附件+身份差异、过敏未知、完整资料+跨日期用药变化。
- 提供实际文字 PDF、粘贴文本、损坏／扫描／混合页测试文件；测试文件可通过确定性脚本生成。
- 单独存预先生成的 demo run／review 初始数据和完成前后状态，schema 检验；公共样本与隐藏测试集清楚区分。

## 验收

- [x] 每个候选 gold Fact／Finding 的依据可以由原文人工重查，不靠被测模型自评标签；实际人工确认尚待完成。
- [x] 清单和样本 manifest 自洽，6 个测试包无问题；测试集未复制到开发提示词样例。
- [x] 样本无真实身份与联系方式，显著标识 Synthetic；普通文字 PDF 经 pypdf 回读，异常 PDF 单独标注预期拒绝。
- [x] 所有固定结果符合 MT-01 契约，清单规则和文档页码可对照。
- [ ] 标注规则、复核记录、许可和重生成命令齐全。

验证：fixture/schema 检查、PDF 文字回读、人工逐项标注检查；不调用付费模型。

## 实施证据及阻塞项

实现与完整命令见 [MT-03-EVIDENCE](../MT-03-EVIDENCE.md)。已完成 30 组合成资料、版本化清单、3 个公开固定结果、严格校验、47 项测试及 PDF 渲染检查。标注规则、许可、重生成命令和待复核模板均已提供。

阻塞项：规范要求操作者逐包核对标注；当前候选标注由编码代理编写，不能冒称经过人工／临床专家确认。需要按 [标注规程](../../../fixtures/referral-review/ANNOTATION.md) 保存实际签核记录并处理发现的问题后，才可标记 DONE。详情见 [复核记录](../../../fixtures/referral-review/REVIEW-LOG.md)。
