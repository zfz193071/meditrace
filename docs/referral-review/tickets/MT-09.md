# MT-09 确定性清单与差异识别

目标：将已验证事实与 manifest 转为明确、可复现的待核对事项。

先读：[C01—C08](../PRODUCT.md)、[规则、身份与时间](../DOMAIN-AND-API.md)。范围：纯函数 checklist Module，不依赖网络／数据库。

## 实施范围

- 完整性、unknown、身份差异、同时间直接相斥陈述、附件匹配不明、解析质量规则。
- 缺失项携带 rule/checklist_version、checked_document_ids 和覆盖说明；只引用存在的文字。
- 对模型提出的差异候选再次检查事实、字段和时间；不产生医疗风险分或诊疗判断。
- 固定 Findings 排序与稳定指纹，同输入／清单结果一致。
- 对清单版本未知、解析覆盖不完整明确拒绝或标注不可自动核对，不伪造完整性结论。

## 验收

- [ ] C01—C08 全覆盖；provided-none／unknown／not-provided 行为分别正确。
- [ ] DOB 矛盾引用两边，姓名不同不自动判定为同一患者；歧义日期不强行转换。
- [ ] 不同日期剂量变化不报同时间冲突，同时间直接相斥时有双方证据。
- [ ] 附件只标“未找到匹配”，不推出未检查；全部成功读取范围可查看。
- [ ] 相同输入多次运行结果与排序一致，规则测试不调用模型。

验证：golden fixture 和反例测试；MT-20 汇总实际提取+规则的端到端质量。
