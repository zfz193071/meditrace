# MT-04 GitHub 登录、会话与归属控制

目标：所有私人资料都能映射到经过服务端验证的账号，并支持安全的登录返回。

先读：[身份、会话与 CSRF](../DOMAIN-AND-API.md)。范围：FastAPI identity 模块和 `/auth/*`，不接入 Next.js 同名认证路由。

## 实施范围

- GitHub OAuth callback、一次性 state 与浏览器绑定、支持时的 PKCE、稳定 subject 映射；回跳路径白名单。
- 数据库不透明会话、cookie 属性、过期、退出／账号停用；会话只保存 token 哈希。
- 集中提供 require_owner，所有后续子资源访问调用同一身份 Interface。
- Origin／CSRF 验证覆盖变更操作；OAuth／Stripe 使用专有校验，不能成为通用免检入口。
- 登录／退出／过期 UI 状态与错误反馈；示例无需登录，自定义 workspace 需要登录。
