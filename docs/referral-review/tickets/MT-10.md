# MT-10 会员、配额、预算与并发账本

目标：所有模型请求必须先获得数据库原子授权与预算预留。

先读：[权益与成本账本](../DOMAIN-AND-API.md)。范围：usage Module、membership 查询、PostgreSQL 锁与费用记录。实际支付由 MT-17 发放权益，本票测试使用隔离 fixture，不提供生产 grant 后门。

## 实施范围

- 会员有效期／剩余次数／已预留次数、邀请名单、环境和模型开关校验。
- 原子预留账号次数、账号／全站并发槽、UTC 日／月费用；锁顺序固定，成本整数化。
- 成功、已知失败、unknown、usage 缺失、跨日、价格变更和实际成本超预留的结算规则。
- 共享存储限流：尝试频率、失败次数；上传与导出也受各自配额，不能仅限制 UI。
- 实现只读用量信息，禁止返回别人的费用或名单；配置缺失 fail closed。

## 验收

- [ ] 多进程 PostgreSQL 竞争不会突破 1 个账号运行、2 个全站运行、剩余次数或两个预算桶。
- [ ] 重复 reserve／settle 不重复扣费；同 run 不可创建第二条 reservation。
- [ ] failed 释放成功次数但记实际成本；unknown 保留上界预算，不盲目退费。
- [ ] 到期、取消、零预算、伪造前端会员／名单、普通沙箱付款均不能触发未授权真实请求。
- [ ] 会员到期不锁定已授权资料的手动编辑、复制或导出。

验证：数据库竞争、时钟注入、账本不变量及成本故障测试；SQLite 通过不作为本票最终依据。
