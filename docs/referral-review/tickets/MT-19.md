# MT-19 可观测性、就绪检查与运维手册

目标：能诊断失败和成本问题，能恢复未知状态，日志不泄露资料。

先读：ARCHITECTURE 执行／恢复、QUALITY 外部配置。范围：结构化日志、readiness、运维 CLI、部署配置说明。

## 实施范围

- 日志字段：request_id、run_id、阶段、错误码、耗时、mode、模型版本、tokens、估计／实际成本；不记录原文／完整响应／凭据。
- `/readiness` 只读验证 DB、迁移、清单，503 明确不可就绪；`capabilities` 说明可用模式但不泄露邀请名单。
- 管理命令可查询／reconcile unknown run、补处理支付事件、重试清理、查看日月预算；默认只读，变更需明确参数。
- 运维手册包含模型不可用、费用未知、价格变更、支付回调失败、清理积压和函数时限的排查／恢复步骤。
- 异常资金、持续失败和维护失败有通知路径；通知仅含元数据，不传患者或合成文档全文。

## 验收

- [ ] 超时／失败可从 request_id 关联状态和账本，错误消息不含秘密。
- [ ] GET readiness 不创建记录、不调用 AI／支付／链上，数据库不可用返回 503。
- [ ] 运维端点普通 session 无权访问，错误密钥拒绝，密钥不在 URL。
- [ ] 日志测试注入秘密和原文哨兵，日志／错误响应不包含这些值。
- [ ] 模拟故障后按手册能恢复状态或准确保留 unknown，无手工直接改账本的隐含步骤。

验证：日志脱敏／运维鉴权测试、readiness 故障测试、runbook 演练。
