# MT-05 私有文档存储与上传控制

目标：有身份隔离、有配额、有失败补偿的来源文件输入。

先读：[输入限制](../PRODUCT.md)、[documents Interface](../ARCHITECTURE.md)。范围：本地私有文件与 Vercel Private Blob Adapter、上传／下载路由。

## 实施范围

- 单文件流式读取、实际字节限制、MIME+文件头校验，拒绝任意 URL、路径穿越、压缩包和非支持类型。
- 上传前事务预留账号／全站存储与文件数配额，并发上传也不越界；失败按实际落盘及补偿状态结算 reservation。
- 对象键使用服务端 ID 与随机部分，不用患者名／原文件名；对象不可覆盖。
- DB／Blob 跨系统失败写 cleanup job；下载通过 document_id 做归属校验，设置 no-store/nosniff。
- 存储 Interface 提供 write/read/delete，真实 Blob 不使用公开桶或向前端返回 token。

## 验收

- [ ] 2 MiB 边界、谎报 Content-Length、并发超额、文件名攻击被正确处理。
- [ ] 账号 A 无法通过 ID、对象键、缓存或 URL 读取 B 的文件。
- [ ] Blob 成功 DB 失败、DB reservation 成功 Blob 失败均可恢复，不产生永久配额占用。
- [ ] 实际 Private Blob 完成上传／鉴权读取／删除，未授权直读失败。
- [ ] 本地 Adapter 文件不落在 public 或仓库跟踪目录中。

验证：存储契约测试、PostgreSQL 并发测试、实际供应商小型合成文件往返。
