## 完成的定义

本文件是 V1 最终验收依据。文档已定义、单页截图正常、Fake 测试通过或部署命令启动，都不等于项目完成。必须有：功能闭环、真实外部集成记录、受控真实模型评估、可访问线上版本，以及对应求职材料。

开发期自动测试默认 Fake Adapter／固定录制响应，禁止自动浏览器发送 AI 请求或点击触发生成的按钮，包含模拟生成按钮。浏览器可测试固定示例选择、原文定位、人工审核、导出；网络 Mock 必须在固定结果读取层完成，而非伪装成已经验证真实模型。真实模型评估使用操作者明确开启的 CLI 或用户手动触发，不由自动浏览器执行。

## 模型与规则评估

固定至少 30 份合成 Packet，每包 1—5 份文档，人工编写 ground truth 并检查来源。10 份开发集、20 份冻结测试集；标注版本和划分写 manifest，调参后不得把看过的测试集继续称为未见样本。测试集至少包含 5 份无问题包，并覆盖 Q03—Q08、提示注入、附件模糊匹配、数字／单位和日期歧义。每份可以覆盖多个情形。

标注包括：事实与原文跨度、清单是否满足、预期 Finding 类型及关联字段、应保留的未知状态、允许的规范化和禁止推断。缺失标签由完整输入人工审阅得出，不由待测模型自评生成。标注复核记录由操作者检查并保存；不宣称经过临床专家验证。

同时提供两个可运行的基线：无模型的简单字段／关键词基线、当前提取+规则实现。仅将原文归纳成摘要不能直接输出 Finding 时，报告其不适用项，不捏造可比较指标。

| 指标 | 定义与首版发布门槛（目标，尚未达到） |
| --- | --- |
| 引用完整性 | 所有采纳事实的引文存在且 offsets/hash 对应；100% |
| 引用支持性 | 人工标注判断引文实际支持该事实；冻结集 ≥95%，不能只算字符串存在 |
| 关键事实准确性 | 姓名／DOB／药名剂量／过敏状态／数值单位的抽取正确率 ≥95%，逐项报告样本数；任何捏造关键事实是阻断缺陷 |
| Finding precision／recall | 按 `(packet,rule,kind,field)` 匹配，分别 ≥90%；报告 TP/FP/FN；分类型同时列出 |
| 无问题包误报 | 报告包级和事项级误报；冻结集至少 5 份负例不得产生身份不一致误报 |
| 确定性回归 | Q03—Q20 对应的规则／权限／资金／状态不变量全部通过 |
| 成本 | 报告输入／输出 tokens、已知实际成本与估算成本；未知单列，不填写虚构价格或零成本 |
| 延迟 | 标准包 ≤5 页，至少 20 次测量；首版目标 p95 ≤90 秒；超时和失败另报，不剔除后冒称全样本指标 |

真实模型测试命令必须显式 `--provider real --max-cost-usd <cap>`，默认 Fake；操作前显示样本数、模型、价格版本、费用上界和输出位置，真实请求需用户明确授权预算。CLI 使用独立评估账本和同一个费用预留机制，不能绕过全站预算／留下无上限循环；失败不自动重试模型。文件仅含合成资料。可由操作者逐例运行，最终合并报告，不要求自动浏览器测试。

报告保存 commit、schema/checklist/prompt/parser/model 版本、样本划分、环境、日期、完整分母、失败项和最差案例。录制响应用于离线回归，必须标注 replay，不代替真实模型成绩。阈值失败时修实现或减少已声明支持范围并更新规格／测试，不能只删除失败样本或改宣传文案。

## 工程检查

- 前端类型检查、生产 build、相关交互测试；后端模块测试、API 契约测试；OpenAPI 生成文件无漂移。
- PostgreSQL 集成覆盖多实例额度竞争、事务回滚、唯一约束、lease 和幂等；SQLite 成功不能替代这一项。
- 存储、OAuth、Stripe 的异常路径用 Fake／本地签名事件测试；真实供应商测试环境各做一次实际往返并留脱敏证据。
- 浏览器测试使用独立后台会话，不切换用户前台，不干扰其他终端标签页，不启动／停止用户本地服务。
- 视口至少 1440×900、1024×768、390×844；键盘可完成示例审核，focus 可见，警示不只靠颜色，屏幕阅读器能读状态。
- PDF 实际渲染检查短稿与长稿，确认分页、字体和无截断；截图仅使用合成数据。
- 供应链检查记录工具版本和可达生产漏洞；无未处置的可达高危问题。依赖升级与 UI 回归在 MT-01／22 完成。
