# MediTrace 对话页面布局改造规格

> **规范 ID**: SPEC-0007  
> **版本**: 1.0.0  
> **状态**: Ready for Agent  
> **创建日期**: 2026-08-28  
> **参考设计**: Doubao Chat (https://www.doubao.com/chat)  
> **关联页面**: `/conversations`

---

## Problem Statement

作为用户，我目前在 `/conversations` 页面看到的布局不够现代化：
- 对话列表和聊天区域的比例不够合理
- 缺少快速返回主页的导航
- 侧栏无法折叠，占据过多空间
- 整体视觉风格与主流 AI 聊天应用（如 Doubao Chat）有差距

这导致用户体验不够流畅，操作效率较低。

---

## Solution

参考 Doubao Chat 的布局设计，重构 `/conversations` 页面：
- **左侧侧栏**：会话列表，支持折叠/展开
- **右侧主区域**：占据全部剩余空间，显示聊天内容
- **导航增强**：聊天区域左上角添加返回主页按钮
- **响应式优化**：侧栏折叠时聊天区域自动扩展

## User Stories

### 布局与导航

1. 作为用户，我希望看到左侧侧栏显示会话列表，右侧显示聊天内容，以便获得清晰的视觉分区
2. 作为用户，我希望侧栏可以折叠/展开，以便在需要时获得更多聊天空间
3. 作为用户，我希望折叠侧栏后聊天区域自动扩展至全屏，以便更好地阅读对话
4. 作为用户，我希望在聊天区域左上角看到返回主页的图标，以便快速导航到首页
5. 作为用户，我希望返回主页图标清晰可见且易于点击，以便快速跳转
6. 作为用户，我希望侧栏展开/折叠时看到平滑的过渡动画，以便获得流畅的视觉体验
7. 作为用户，我希望页面刷新后保持侧栏的展开/折叠状态，以便维持我的偏好设置
8. 作为用户，我希望在小屏幕（移动端）上自动隐藏侧栏，以便适应小屏设备
9. 作为用户，我希望在移动端通过汉堡菜单打开侧栏，以便在手机上查看历史对话
10. 作为用户，我希望布局在不同分辨率下都能自适应，避免出现滚动条或内容被遮挡

### 左侧侧栏（会话列表）

11. 作为用户，我希望在侧栏顶部看到"新建对话"按钮，以便快速创建新会话
12. 作为用户，我希望侧栏宽度可配置（默认 300px），以便根据个人偏好调整
13. 作为用户，我希望会话列表按更新时间倒序排列，以便优先看到最新的对话
14. 作为用户，我希望每个会话项显示标题、最后消息预览和更新时间，以便快速识别
15. 作为用户，我希望当前选中的会话有高亮背景，以便知道正在查看哪个对话
16. 作为用户，我希望点击会话项可以切换查看内容，以便浏览历史记录
17. 作为用户，我希望会话项支持删除操作（显示删除按钮），以便清理不需要的记录
18. 作为用户，我希望删除前弹出确认对话框，防止误删
19. 作为用户，我希望在侧栏为空时看到友好的提示信息，以便知道如何开始
20. 作为用户，我希望侧栏支持滚动查看更多会话，以便查看所有历史记录

### 右侧聊天区域

21. 作为用户，我希望聊天区域占据右侧全部空间，以便获得最佳的阅读体验
22. 作为用户，我希望在未选择会话时看到引导提示，以便知道下一步操作
23. 作为用户，我希望选择会话后看到对话标题和消息数量，以便了解上下文
24. 作为用户，我希望消息列表支持滚动，以便查看历史消息
25. 作为用户，我希望消息自动滚动到最新消息，以便不需要手动操作
26. 作为用户，我希望用户消息显示在右侧，AI 消息显示在左侧，以便区分角色
27. 作为用户，我希望每条消息显示时间戳，以便了解对话时序
28. 作为用户，我希望 AI 消息支持 Markdown 渲染，以便阅读结构化的诊断结果
29. 作为用户，我希望流式消息显示打字效果，以便感知 AI 正在生成
30. 作为用户，我希望输入框固定在底部，滚动时不被遮挡，以便随时输入

### 返回主页功能

31. 作为用户，我希望在聊天区域左上角看到返回主页图标（如房子图标），以便快速导航
32. 作为用户，我希望返回主页图标在侧栏展开和折叠时都可见，以便随时使用
33. 作为用户，我希望点击返回主页图标后跳转到 `/` 页面，以便回到首页
34. 作为用户，我希望返回主页图标有悬停效果，以便知道它是可点击的
35. 作为用户，我希望返回主页图标与侧栏折叠按钮保持合理的间距，避免误触

### 侧栏折叠/展开功能

36. 作为用户，我希望在聊天区域左上角看到侧栏折叠/展开按钮，以便控制侧栏显示
37. 作为用户，我希望点击折叠按钮后侧栏收起，聊天区域扩展，以便获得更多空间
38. 作为用户，我希望点击展开按钮后侧栏重新显示，以便查看历史对话
39. 作为用户，我希望折叠按钮图标清晰表明当前状态（展开/折叠），以便知道下一步操作
40. 作为用户，我希望折叠/展开时看到平滑的过渡动画（如 0.3s 缓动），以便获得流畅体验
41. 作为用户，我希望在侧栏完全折叠时，返回主页按钮仍然可见，以便保持导航能力
42. 作为用户，我希望在侧栏展开时，折叠按钮和返回主页按钮并排显示，布局合理

### 响应式设计

43. 作为用户，我希望在桌面端（> 1024px）看到双栏布局，以便充分利用大屏
44. 作为用户，我希望在平板端（768px - 1024px）看到可折叠的侧栏，以便灵活调整
45. 作为用户，我希望在移动端（< 768px）自动隐藏侧栏，通过按钮打开，以便适应小屏
46. 作为用户，我希望在移动端打开侧栏时以抽屉形式覆盖内容，以便专注查看
47. 作为用户，我希望在移动端点击遮罩层关闭侧栏，以便快速返回聊天
48. 作为用户，我希望所有按钮在触摸设备上足够大（最小 44x44px），便于点击

### 性能与体验

49. 作为用户，我希望页面加载时快速渲染，首屏时间 < 2 秒，以便获得流畅体验
50. 作为用户，我希望侧栏折叠/展开时没有卡顿，动画流畅，以便感知良好
51. 作为用户，我希望在会话列表加载时看到骨架屏或加载动画，以便知道正在加载
52. 作为用户，我希望在网络错误时看到友好的错误提示，以便了解问题
53. 作为用户，我希望在删除会话时快速响应，无需等待刷新，以便感知高效

## Implementation Decisions

### 技术决策

#### 1. 布局架构

**当前文件**: `src/frontend/app/conversations/page.tsx`

**修改策略**: 在现有页面内进行布局重构，不拆分为多个组件（保持简单）

**布局结构**:
```tsx
<main className="min-h-screen flex">
  {/* 左侧侧栏 - 可折叠 */}
  <aside className={`transition-all duration-300 ${sidebarCollapsed ? 'w-0' : 'w-80'}`}>
    {/* 会话列表内容 */}
  </aside>

  {/* 右侧主区域 */}
  <main className="flex-1 flex flex-col">
    {/* 顶部导航栏 */}
    <header className="flex items-center gap-2 p-4 border-b">
      <button onClick={toggleSidebar}> {/* 折叠/展开按钮 */}</button>
      <button onClick={() => router.push('/')}> {/* 返回主页按钮 */}</button>
    </header>
    
    {/* 聊天内容 */}
    <div className="flex-1 overflow-y-auto">
      {/* 消息列表 */}
    </div>
    
    {/* 输入区域 */}
    <footer className="border-t p-4">
      {/* 输入框 */}
    </footer>
  </main>
</main>
```

#### 2. 状态管理

**新增状态**:
```typescript
const [sidebarCollapsed, setSidebarCollapsed] = useState(false);
const [isMobile, setIsMobile] = useState(false);
```

**响应式检测**:
```typescript
useEffect(() => {
  const checkMobile = () => {
    setIsMobile(window.innerWidth < 768);
    if (window.innerWidth < 768) {
      setSidebarCollapsed(true); // 移动端默认折叠
    }
  };
  
  checkMobile();
  window.addEventListener('resize', checkMobile);
  return () => window.removeEventListener('resize', checkMobile);
}, []);
```

#### 3. 图标选择

**使用现有依赖**: 使用 Unicode 字符或 SVG，避免新增依赖
- 返回主页：`🏠` 或 `<svg>` 房子图标
- 折叠侧栏：`◀` 或 `<svg>` 箭头图标
- 展开侧栏：`▶` 或 `<svg>` 箭头图标

**备选方案**: 如后续需要更丰富的图标，可引入 `lucide-react` 或 `@heroicons/react`

#### 4. 样式方案

**使用现有 Tailwind**: 不新增 CSS 文件，全部使用 Tailwind 类名
- 过渡动画：`transition-all duration-300 ease-in-out`
- 响应式断点：`md:` `lg:` 前缀
- 布局工具：`flex` `flex-col` `flex-1`

#### 5. 本地存储（可选）

**保存侧栏状态**:
```typescript
// 读取
useEffect(() => {
  const saved = localStorage.getItem('sidebarCollapsed');
  if (saved) setSidebarCollapsed(saved === 'true');
}, []);

// 写入
useEffect(() => {
  localStorage.setItem('sidebarCollapsed', sidebarCollapsed.toString());
}, [sidebarCollapsed]);
```

**决策**: 暂不实现，保持简单。如用户反馈需要，后续添加。

### 视觉设计

#### 配色方案（保持现有）

- **主色调**: 绿色 (`bg-green-500`, `text-green-500`)
- **侧栏背景**: `bg-white`
- **聊天背景**: `bg-white`
- **用户消息**: `bg-green-500 text-white`
- **AI 消息**: `bg-gray-100 text-gray-800`
- **选中会话**: `bg-green-50`

#### 间距规范

- **侧栏宽度**: `w-80` (320px)
- **内边距**: `p-4` (16px)
- **消息间距**: `mb-4` (16px)
- **按钮间距**: `gap-2` (8px)

#### 响应式断点

```typescript
// Tailwind 断点
- sm: 640px
- md: 768px  // 移动端/平板分界
- lg: 1024px // 平板/桌面分界
- xl: 1280px
```

**布局策略**:
- `< 768px`: 单栏，侧栏以抽屉形式覆盖
- `768px - 1024px`: 双栏，侧栏可折叠
- `> 1024px`: 双栏，侧栏默认展开

## Out of Scope

以下功能不在本次规格范围内：

### 组件重构

- 不将页面拆分为多个子组件
- 不引入新的 UI 组件库
- 不重构现有的状态管理逻辑

### 功能增强

- 不新增会话搜索功能
- 不新增会话标签/分类
- 不新增会话导出/导入

### 动画效果

- 不实现复杂的过渡动画（如侧栏滑入）
- 不实现消息的入场动画
- 不实现骨架屏加载

### 本地存储

- 不保存侧栏展开/折叠状态
- 不保存用户偏好设置
- 不实现离线支持

### 可访问性（A11y）

- 不添加 ARIA 标签
- 不实现键盘导航
- 不实现屏幕阅读器支持
