# 采用不可变资料版本与模块化单体

2026-10-20：保留 Next.js、FastAPI、Neon 和现有 Vercel Services 部署，将领域逻辑集中在 FastAPI 模块中。资料版本、核对批次与审核快照不可变；人工处理追加记录，避免文件替换或重新生成后旧证据指向新内容。该取舍增加了版本与失效处理成本，但使核对结果可以复现，并保护人工修改。

首版采用有时限的请求内执行与数据库持久化状态，不引入消息队列或常驻 worker，也不依赖响应返回后的后台任务。每批次最多发起一次模型请求；执行中断且供应商结果未知时保留费用预留并要求显式重新运行，不承诺跨供应商的 exactly-once。文件较小且数量受限，超限明确拒绝；规模扩大时再以独立 ADR 引入队列和分块处理。
