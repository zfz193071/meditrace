# Triage Labels

This repo uses the following triage labels for agent skills:

| Label | Description |
|-------|-------------|
| needs-triage | Item needs initial triage |
| needs-info | Item needs more information before proceeding |
| ready-for-agent | Item is ready for agent work |
| ready-for-human | Item needs human review |
| wontfix | Item will not be addressed |

These are the five canonical triage roles with label strings equal to their names.
