# Issue Tracker

This repo uses **GitHub Issues** as its issue tracker.

Agent skills that need to create or read issues will use the `gh` CLI to interact with GitHub Issues.

## Workflow

- Create issues: `gh issue create --title "..." --body "..."`
- Read issues: `gh issue view <number>`
- List issues: `gh issue list`
